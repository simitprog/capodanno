Guida per lo Sviluppatore

Per aggiungere o modificare le location, apri il file index.html nel tuo editor di codice e cerca l'array JavaScript locationsData. 

{

Salva il file, esegui il commit e fai il git push su GitHub. Il sito si aggiornerà in pochi secondi!
